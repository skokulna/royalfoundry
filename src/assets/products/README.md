# Product photos — drop them here

Name each file after the product slug. The site picks them up automatically
on the next build; no code changes needed.

    clamps.jpg        → Electrical line & substation clamps
    ab-switches.jpg   → A/B switches
    earthing.jpg      → Earthing products
    moulds.jpg        → Door & industrial mat moulds
    fabrication.jpg   → Fabrication work

    hero.jpg          → optional wide shot for the home page banner

Accepted: .jpg .jpeg .png .webp

Astro resizes and converts these to WebP at build time, so you can drop
straight-off-the-phone photos in — no need to shrink them first.

Shooting tips
- Daylight, plain background (a workbench or a wall is fine).
- Landscape orientation, roughly 3:2.
- One product per photo, filling most of the frame.
- A finished, clean part photographs far better than a raw casting.
